## Projeto em destaque

### Roraima Mangás

E-commerce Full Stack desenvolvido para uma loja local de mangás e produtos geek. A aplicação foi planejada para ampliar a vitrine digital do negócio e facilitar pedidos locais sem exigir cadastro do cliente.

**Principais funcionalidades**

- catálogo responsivo de produtos;
- pesquisa, filtros, categorias e coleções;
- página individual do produto;
- carrinho de compras;
- geração do pedido e envio pelo WhatsApp;
- painel administrativo com autenticação;
- gerenciamento de produtos, categorias, coleções e banners;
- upload de imagens com Cloudflare R2;
- persistência de dados com Neon PostgreSQL;
- validação de dados e proteção das operações administrativas.

**Tecnologias:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Zod, NextAuth, Prisma, Neon PostgreSQL e Cloudflare R2.
